건축법규 면적·주차 검토기

값을 모두 입력한 뒤 화면 아래의 검토하기 버튼을 누르면 계산됩니다.

01

프로젝트 기본 설정

모든 값은 언제든 수정할 수 있습니다.

02

층별 입력

주차 산정은 B2~5F 전 층을 포함하고, 각 층의 엘리베이터 면적만 제외합니다.

03

주차 기준 설정

현재 값은 기능 테스트용 임시 기준이며 실제 법규 확인 후 변경해야 합니다.

입력을 모두 마쳤나요?

검토 버튼을 눌러 결과를 계산하세요.

입력 중에는 계산하거나 화면을 다시 만들지 않으므로 숫자를 자유롭게 연속 입력할 수 있습니다.

04

검토 결과

층별 면적 결과

전체면적, 엘리베이터 제외면적, 순사용면적을 ㎡와 평으로 표시합니다. 용적률과 주차 산정에는 엘리베이터 제외면적이 적용됩니다.

층 전체면적 엘리베이터 제외 순사용면적 주차 산정면적 주차지수

목표 주차대수까지의 여유 면적

각 용도를 추가한다고 가정했을 때의 참고값입니다.

본 계산 결과는 입력된 면적과 임시 주차기준을 바탕으로 한 설계 검토용 참고값입니다. 실제 허가 및 법정 주차대수는 적용 법령·조례·시설 용도·면적 산정 방식에 따라 달라질 수 있습니다.
