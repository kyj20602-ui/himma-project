# 건축법규 면적·주차 검토기 v6

GitHub Pages에서 실행할 수 있는 HTML·CSS·JavaScript 기반 정적 사이트입니다.

## 주요 기능

- 건축면적 직접 입력
- 검토 날짜 입력
- 프로젝트 이미지 첨부 및 미리보기
- 층별 전체면적, 엘리베이터 제외면적, 실사용면적 계산
- 용적률: 용적률 산입 층의 `전체면적 - 엘리베이터 면적` 합계 기준
- 주차: B2~5F 전 층의 `전체면적 - 엘리베이터 면적` 합계를 단일 기준면적으로 나눔
- A4 가로형 PDF 보고서 출력

## PDF 출력 방법

1. 값을 입력하고 **검토하기**를 누릅니다.
2. **PDF 출력**을 누릅니다.
3. 브라우저 인쇄 창에서 대상을 **PDF로 저장**으로 선택합니다.
4. 용지는 A4, 방향은 가로로 설정됩니다. 브라우저에서 배경 그래픽 옵션을 켜면 화면과 더 유사하게 출력됩니다.

PDF 보고서 상단에는 대지면적, 기본 엘리베이터 면적, 건폐율, 용적률, 주차대수, 주차 여유 면적이 중앙 정렬됩니다. 하단은 좌우로 나뉘며 왼쪽에는 첨부 이미지, 오른쪽에는 층별 면적과 계산식이 표시됩니다.

## 파일

- `index.html`: 화면 및 PDF 보고서 구조
- `styles.css`: 화면 디자인과 A4 가로 인쇄 스타일
- `app.js`: 입력, 계산, 이미지 저장, PDF 출력 기능
- `README.md`: 사용 안내

## 배포

기존 GitHub 저장소의 네 파일을 모두 교체한 뒤 커밋합니다. 배포 후 브라우저에서 `Ctrl + F5`로 강력 새로고침하세요.

## 주의

첨부 이미지는 브라우저 localStorage에 저장되므로 크기가 큰 이미지는 저장 용량 제한에 걸릴 수 있습니다. 12MB 이하 이미지만 선택할 수 있도록 제한되어 있습니다. 실제 허가 검토 시 적용 법령과 조례를 별도로 확인해야 합니다.
