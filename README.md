# 건축법규 면적·주차 검토기

GitHub Pages에서 바로 실행할 수 있는 HTML·CSS·JavaScript 기반 정적 사이트입니다.

## 이번 버전의 핵심 변경

- 숫자를 입력할 때 즉시 계산하지 않습니다.
- 모든 값을 입력한 뒤 화면 아래의 **검토하기** 버튼을 누르면 계산됩니다.
- 입력하는 동안 층별 카드나 입력창을 다시 생성하지 않으므로 포커스가 사라지지 않습니다.
- 검토 버튼을 누르면 건폐율, 용적률, 층별 순면적, 주차지수와 목표 주차대수까지의 여유 면적을 계산합니다.

## 포함 파일

- `index.html`: 화면 구조
- `styles.css`: 디자인
- `app.js`: 입력 저장 및 계산 기능
- `README.md`: 안내 문서

## GitHub에 적용하는 방법

기존 저장소의 아래 파일을 전부 새 파일로 교체합니다.

- `index.html`
- `styles.css`
- `app.js`
- `README.md`

파일 교체 후 Commit changes를 누르고 GitHub Pages 배포가 끝날 때까지 기다립니다.
브라우저에서 `Ctrl + F5`를 눌러 강력 새로고침합니다.

## 현재 계산 방식

- 건축면적: 1층 전체 바닥면적
- 건폐율: 건축면적 ÷ 대지면적 × 100
- 용적률 산입면적: `용적률 산입`이 체크된 층의 **전체 바닥면적에서 각 층 엘리베이터 면적을 제외한 값의 합계**
- 엘리베이터 제외면적: 전체면적 − 엘리베이터 면적
- 순사용면적: 전체면적 − 엘리베이터 면적 − 피난동선 면적
- 주차 산정면적: **B2층부터 5층까지 모든 층의 전체 바닥면적에서 각 층 엘리베이터 면적만 제외한 값**
- 주차지수: 주차 산정면적 ÷ 용도별 1대당 면적
- 예상 법정 주차대수: 합산 주차지수를 올림한 값

## 주의

주차 기준은 현재 테스트용 임시값입니다. 실제 법규 및 서울시·관할구 조례를 확인하여 수정해야 합니다.
