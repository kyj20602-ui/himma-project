# 건축법규 면적·주차 검토기 v9

GitHub Pages에서 실행할 수 있는 HTML·CSS·JavaScript 기반 정적 사이트입니다.

## 주요 기능

- 건축면적을 엘리베이터 포함 면적으로 직접 입력
- 검토 날짜 입력
- 프로젝트 이미지 첨부 및 미리보기
- 층별 전체면적, 엘리베이터 제외면적, 실사용면적 계산
- 건폐율: 입력 건축면적에서 `1F 엘리베이터 면적`을 자동 제외해 산정
- 건폐율: 허용 건축면적과 잔여·초과 면적 표시
- 용적률: 용적률 산입 층의 `전체면적 - 엘리베이터 면적` 합계 기준
- 용적률: 허용 연면적과 잔여·초과 면적 표시
- 주차: B2~5F 전 층의 `전체면적 - 엘리베이터 면적` 합계를 단일 기준면적으로 나눔
- A4 가로형 PDF 보고서 출력

## PDF 출력 방법

1. 값을 입력하고 **검토하기**를 누릅니다.
2. **PDF 출력**을 누릅니다.
3. 브라우저 인쇄 창에서 대상을 **PDF로 저장**으로 선택합니다.
4. 용지는 A4, 방향은 가로로 설정됩니다. 브라우저에서 배경 그래픽 옵션을 켜면 화면과 더 유사하게 출력됩니다.

PDF 보고서 상단에는 건폐율·용적률 산정면적, 허용면적, 여유면적과 주차 여유면적이 2행으로 표시됩니다. 하단은 좌우로 나뉘며 왼쪽에는 첨부 이미지, 오른쪽에는 층별 면적과 계산식이 표시됩니다.

## 파일

- `index.html`: 화면 및 PDF 보고서 구조
- `styles.css`: 화면 디자인과 A4 가로 인쇄 스타일
- `app.js`: 입력, 계산, 이미지 저장, PDF 출력 기능
- `README.md`: 사용 안내

## 배포

기존 GitHub 저장소의 네 파일을 모두 교체한 뒤 커밋합니다. 배포 후 브라우저에서 `Ctrl + F5`로 강력 새로고침하세요.

## 주의

첨부 이미지는 브라우저 localStorage에 저장되므로 크기가 큰 이미지는 저장 용량 제한에 걸릴 수 있습니다. 12MB 이하 이미지만 선택할 수 있도록 제한되어 있습니다. 실제 허가 검토 시 적용 법령과 조례를 별도로 확인해야 합니다.


## v6.1 버튼 작동 수정

- 일부 브라우저에서 지원되지 않는 `structuredClone()` 의존성을 제거했습니다.
- 검토하기와 PDF 출력 이벤트 초기화를 안정화했습니다.
- PDF 출력 버튼은 검토 전에도 누를 수 있으며, 누르면 먼저 자동 검토한 뒤 인쇄창을 엽니다.
- 이미지가 커서 브라우저 저장 한도를 넘더라도 계산과 PDF 출력은 계속 작동합니다.


## v6.2 PDF 그래픽 개선

- PDF 상단의 ‘건축법규 면적·주차 검토’ 제목을 제거했습니다.
- 검토 날짜를 PDF 왼쪽 하단으로 이동했습니다.
- 오른쪽 하단 문구를 `himma 사옥 Project · 면적 검토`로 변경했습니다.
- 날짜와 프로젝트 문구에 동일한 글자 크기, 굵기, 색상을 적용했습니다.
- 층별 표의 ‘전체 / EL 제외 / 실사용’을 열 머리글로 분리해 숫자와 텍스트가 겹치지 않도록 했습니다.
- PDF용 글자 크기와 행 간격을 확대했습니다.
- 프로젝트 저장 함수의 재귀 호출 오류를 수정했습니다.


## v7.0 건폐율·용적률 여유면적 추가

- 건축면적은 엘리베이터를 포함한 값으로 입력합니다.
- 건폐율 산정 시 1F의 엘리베이터 체크 여부와 면적을 읽어 자동으로 제외합니다.
- 허용 건축면적 = 대지면적 × 허용 건폐율
- 건폐율 여유면적 = 허용 건축면적 − 건폐율 산정면적
- 허용 용적률 면적 = 대지면적 × 허용 용적률
- 용적률 여유면적 = 허용 용적률 면적 − 용적률 산입면적
- 화면 결과 카드와 A4 PDF 보고서에 허용면적·여유면적을 함께 표시합니다.


## v8 수정 사항

- 건폐율 계산 시 층별 1F 값이 아니라 **기본 엘리베이터 면적**을 건축면적에서 항상 자동 제외합니다.
- PDF 상단에 계획 건폐율·건폐율 산정면적·허용 건축면적·건폐율 여유면적을 함께 표시합니다.
- PDF 상단에 계획 용적률·용적률 산입면적·허용 용적률 면적·용적률 여유면적을 함께 표시합니다.
- PDF 계산식에도 건폐율과 용적률의 퍼센트 및 면적 내역을 병기합니다.


## v9 PDF 레이아웃 수정

- PDF 상단에서 허용 건축면적·허용 용적률 면적 등 개별 허용면적 카드를 제거했습니다.
- 상단은 대지면적, 기본 엘리베이터, 계획 건폐율, 계획 용적률, 주차대수, 주차 여유면적만 한 줄로 표시합니다.
- PDF 하단 계산 결과를 건폐율·용적률·주차 각 한 줄로 정리했습니다.
- 각 줄에서 `산정 / 허용 / 여유`가 나란히 표시되도록 변경했습니다.
- 허용값은 면적이 아니라 건폐율·용적률의 허용 비율과 목표 주차대수로 간략화했습니다.
- 하단 주차 산정 문구가 페이지 경계를 넘어가지 않도록 열 너비와 글자 크기를 조정했습니다.
